# 输入文件目录

把你自己的业务清单放在这里，再按 `config/` 中对应配置填写文件名。

常用文件名示例：

- `blocks.csv`：3.0 普通区块清单；
- `components.xlsx`：3.0 组件清单；
- `ranking.xlsx`：区块排名清单；
- `v4-blocks.csv`：4.0 编辑器区块清单；
- `online-status.xlsx`：3.0 上线/下线区块清单；
- `v3-block-json/`：3.0 全量任务需要的 JSON 文件。

增长引擎批量审计还需要先完成对应的编辑器铺页，并使用生成的状态文件作为输入。

不要把账号、密码、Cookie 或浏览器缓存放在此目录中。
